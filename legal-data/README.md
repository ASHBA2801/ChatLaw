# Legal Data

Verified, **structured** legal resources that support the application but are
**not** the original source documents.

`Law_files/` remains the immutable original corpus — never copy the entire
dataset here.

## Sub-directories

| Path | Intended content |
| --- | --- |
| `sources/` | Curated / verified references to legal sources, official gazette links, etc. |
| `forms/` | Standard legal forms (writs, complaints, etc.) |
| `courts/` | Court directories, jurisdiction metadata, court-specific resources |
| `metadata/` | Structured metadata about laws, documents, and resources |
