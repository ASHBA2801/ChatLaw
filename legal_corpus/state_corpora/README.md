# Stage 3 — State corpora (scaffolding only)

This directory is reserved for **State / Union Territory** statute corpora.

- Catalog entries use `jurisdiction_level: STATE` and `ingestion_stage: stage_3`.
- No PDFs are ingested in this phase.
- Per-state folders (e.g. `MH/`, `KA/`, `TN/`) will be added when Stage 3 begins.

See `legal_corpus/acts/catalog.json` placeholders:
`STATE_RENT_PLACEHOLDER`, `STATE_RERA_PLACEHOLDER`, `STATE_LABOUR_PLACEHOLDER`,
`STATE_FAMILY_PLACEHOLDER`, `STATE_LAND_PLACEHOLDER`.
