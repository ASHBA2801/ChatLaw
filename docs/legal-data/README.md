# Legal Data Documentation

Documentation for the `legal-data/` directory — verified, structured legal
resources that are **not** the original source documents.

## Contents

- [Legal data guide](./legal-data.md) — what lives in `legal-data/` and how it
  differs from `Law_files/`.

## Key rules

- `Law_files/` is the immutable original corpus; never copy the entire dataset
  into `legal-data/`.
- `legal-data/` holds curated, structured resources (forms, courts, sources,
  metadata).
